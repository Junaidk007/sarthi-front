# Sarthi AI — Frontend

Multi-Agent Knowledge Intelligence Platform built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

Make sure you have Node.js and npm installed.

```sh
npm install
npm run dev
```

## Tech Stack

- **Framework**: TanStack Start & React 19
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **State & Queries**: TanStack Query
